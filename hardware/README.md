# PARAM KEY hardware documentation

Reference documentation for the PARAM KEY remote: the schematic, pinout, parts list, case models and
the case's structural analysis. Open firmware, open HA integration, documented hardware: the board and
case design files are proprietary, and this folder only documents them. Unlike the rest of the
repository it is not MIT licensed: see [LICENSE](LICENSE).

| Path | What |
|---|---|
| `schematic/` | Full schematic (PDF) |
| `pinout.md` | ESP32-S3 GPIO assignments |
| `parts.md` | Function-level parts list |
| `case/` | Case and keycap models (STL) and renders |
| `fea/` | Case FEA result plots |

This folder is generated from the private hardware sources; changes made here are overwritten.
