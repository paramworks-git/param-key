PARAM KEY

Install the bridge, or update a remote, straight from this page. Use Chrome or Edge on a computer, and a USB cable that carries data (some only charge).

Bridge

Any ESP32 board: ESP32, ESP32-S3 or ESP32-C3. Give it a USB power supply near where you use the remote, and use it only as a bridge (not also as a Bluetooth proxy).

  1. Plug the board into this computer and select Install, then pick its port.
  2. When asked, choose your Wi-Fi network and enter its password.
  3. In Home Assistant, open Settings → Devices & services. Under Discovered, add the ESPHome device param-key-bridge-…, then PARAM KEY, which asks to let the bridge send key presses to Home Assistant.
This browser can't reach USB devices. Open this page in Chrome or Edge on a computer. USB access needs a secure page (https).

Already installed? The same button changes its Wi-Fi network. Updates arrive in Home Assistant: the bridge shows Firmware update available.

Remote

Remotes come ready to use. Use this to update one, or to reinstall it.

  1. Connect the remote with a USB-C cable and select Update remote, then pick its port.
  2. Leave Erase device unchecked: erasing removes its pairing, and you would pair it with Home Assistant again.
This browser can't reach USB devices. Open this page in Chrome or Edge on a computer. USB access needs a secure page (https).

The remote doesn't show up? Unplug it, hold home while plugging it back in, and try again. Unplug and replug it once the update is done.
